# 44 Bar Ranch

Website for 44 Bar Ranch, a small family ranch in rural Texas.

The live site is [https://44barranch-test.jay-t-clark.workers.dev](https://44barranch-test.jay-t-clark.workers.dev). Merging to `main` publishes a new version.

To change words or add photos, read [EDITING.md](EDITING.md). You can do that on github.com. No local setup required.

## Local commands

From the project folder:

| Command | What it does |
| --- | --- |
| `npm install` | Installs dependencies |
| `npm run dev` | Opens a local preview at `localhost:4321` |
| `npm run build` | Builds the site into `./dist/` |
| `npm run preview` | Builds, then previews with Wrangler |

Built with Astro and deployed on Cloudflare Workers.
